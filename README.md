# NPCMounts

人形坐骑法术，当前为 **0.4.4 Y4候选版**，只构建 SE 1.5.97。构建及离线验证不等于游戏验收。

当前五个主要魔法使用「人魅-」全名：人形坐骑化、解除坐骑化与束缚、固定NPC、捕获、牵引坐骑。卸装并入普通坐骑化，使用INI/中文菜单的UndressOnConvert勾选项，默认关闭。旧版本说明中的字母及旧法术为历史记录。
0.1.0、0.1.1及0.1.3均有用户确认的故障。0.1.3实测玩家移动而NPC留在原地、无动作；0.1.4修正控制器同步及更新顺序，并加入每次骑乘最多8条同步日志。已离线检查，尚未游戏复测，不能标记为可用正式版。详情见 docs/REVIEW.md。
0.1.5源码审查修正动作派系等级晚于动画事件发布、死亡/剧情自动还原被普通下骑条件阻挡的问题。尚未证明这些修正解决了NPC不跟随或无动作的主要故障。
0.1.5后续实测确认移动跟随，但仍有朝向不跟随、骑手奔跑/其他动作穿透、无法下骑及上下抖动。0.1.6针对这五项修改，改用人形爬行动作；已编译和离线验证，游戏复测尚未完成。

## 操作

- 0.4.1新增：成功骑乘后记录最近一个仍在坐骑形态的NPC。玩家过门、快速旅行或可检测的瞬移后，目的地就绪并等待0.75秒，寻找附近落脚点后单次传送它；不是持续贴身跟随。固定中的目标按用户选择保留原地，牵引中的目标不抢LeashFramework控制权。解除坐骑化、删除或死亡清除记录；骑另一个目标替换记录，不回退更早的坐骑。记录保存于TRVL v1，旧存档升级后须再骑一次建立记录。读档本身不触发搬运。详见docs/AUDIT-0.4.1.md。

- `人魅-人形坐骑化`：瞄准一个已加载、存活、使用兼容人形骨架的 NPC 施放；转换时记录并卸下左右手武器、盾牌、法杖和手持法术。勾选“坐骑化时卸下服装与护甲”后，另外记录本插件实际卸下的服装实例；解除时恢复记录的手持装备、法术和仍在背包中的原服装。
- 对转换目标按游戏交互键：播放插件姿态层的上骑过渡后骑乘；骑乘中长按下骑键严格超过0.25秒，播放下骑过渡后释放。不上送原版人马上下骑事件。
- 使用正常移动、奔跑和跳跃键。跳跃不被禁用。
- `人魅-解除坐骑化与束缚`：优先还原当前坐骑，其次还原准星目标；准星没有目标时恢复全部转换。
- `人魅-固定NPC`：仅接受坐骑形态NPC；先完整解除坐骑化并恢复人形和装备，再用正常人形束缚姿态固定并连接固定桩绳索。再次施放解除固定。需要LeashFramework。
- `人魅-捕获`：用准星选择任意已加载、存活NPC，不要求人类种族或敌对。记录并卸下双手武器与法术，停止战斗、抑制敌意并原地捆绑；不生成木桩、不调用牵引框架，也不因束缚动作短暂位移自动释放。再次施放恢复捕获前装备、AI及原有敌对关系。女性化巨人等非人类行为图使用按骨骼名称映射的上身束缚层；实际姿态仍需游戏验收。
- `人魅-牵引坐骑`：无本插件绳索时添加玩家持绳、NPC跟随；再次施放解除。创建中可取消，固定桩绳同时解除固定、删除桩/绳环，保留坐骑化。不覆盖第三方绳索。旧“解除牵引”已学魔法在加载时迁移到此魔法，旧书改教此魔法；内部旧记录保留兼容。
- 旧独立卸装法术在加载时迁移为普通坐骑化，旧书改教普通坐骑化，不强制打开卸装开关。原敌对束缚 FormID 直接复用为“人魅-捕获”，避免给旧存档增加重复法术记录。
- 骑乘期间通过可选TDM V1接口申请暂停方向接管，下骑/读档归还本插件所有权；不改TDM配置，不释放其他插件请求。允许后退时，映射到Alt的Back不再被Alt拦截覆盖。
- 任何位置均可下骑，包括空中；可找到无遮挡侧边时向侧边下骑，否则原地播放，不再提示移到开阔地。B对当前目标先下骑再还原；死亡/剧情等紧急退出立即释放。无目标B对未加载引用保留请求，待其加载后还原。
- 骑乘期间过滤Ctrl/Alt、后退、潜行、拔武器、普通攻击/施法及龙吼输入；保留前进/横移、奔跑、跳跃、交互下骑和B施法。菜单输入正常，键盘重映射到Ctrl/Alt的动作也会被过滤。通过独立轮询键盘或直接脚本驱动的第三方动作不属于此输入队列保证范围。
- 不再一概拒绝Scene内NPC；坐家具的目标先退出交互。仍拒绝未加载、死亡、倒地等特殊生命状态、击杀动作、已骑其他坐骑或不兼容动画骨架的目标，显示具体原因。

不再自动添加法术。ESP提供七本法术书（五本当前功能、两本旧版兼容），使用AddItemMenu检索NPCMounts.esp，或控制台检索 `help NPCMountsTome` 后按实际BOOK编号获取并阅读；未加入商人或世界容器。转换和装备快照保存在 SKSE co-save；读档保留转换，但不自动恢复骑乘。
卸载前用 B 的无目标操作解除全部转换，保存并退出。不能承诺直接删 DLL 仍能恢复暂停的 NPC。

## 实现

- NPC 的种族、性别、身高、外貌、装备、派系原记录均不改；可临时修改已转换引用的scale，B恢复原值。
- 给目标引用增加本插件的独立标记派系；保持 AI 启用，用可恢复的 restrained 状态约束自主行为，避免 EnableAI(false) 冻结动画。B停止冲刺/移动、移除标记后恢复原生命状态、AI开关和接管标志；不覆盖已经死亡目标的生命状态。co-save版本4保存待还原请求，兼容读取版本1/2/3。
- 18 段 99 轨人形兼容动画：F NPC Mount来源的人形爬行动作、固定骑手姿势、保留跳跃事件的骑手片段及中性附加层。背部乘坐点逐帧固定；空中保持爬行姿态，高度由玩家物理跳跃驱动，不再叠加马来源的跳跃姿势。
- OAR 按引用派系等级选动作；普通 NPC 没有该标记，不匹配。
- 玩家原生控制器负责行走、墙体碰撞和跳跃。骑乘期间双方抑制角色间碰撞，下骑归还原标志；坐骑保持模拟。每个玩家更新帧只同步一次NPC引用与控制器，NPC更新不再反向重复同步；SetAngle同步参考旋转。按玩家物理控制器水平速度选动作，保留步态滞回与按时间转向。只在运动状态变化时发事件。
- 骑手坐姿的位置写入动画 COM 轨道，镜头轨道保留正常人形待机值；不再在更新前后移动任何骨骼节点或重复向下更新场景图。普通背骨横向基准仍为0，仅加入限幅的爬行动作起伏；`RiderSway`默认0.35、范围0—1。玩家或NPC进入水中更换动画图时按骨骼名称重新绑定，骑手继续使用骑姿、NPC继续使用爬行动作。极端身高/体型的实际贴合仍需游戏校准。
- 上下骑只播放包内31帧人形姿态层，不调用原版人马配对动画图事件。对话启动、强制招呼及标准 DialogueMenu 对转换目标被拦截。
- 不删除其他 Mod 的对话记录，不保证拦截第三方自定义界面或绕过正常入口的脚本。

运行时依赖：SKSE 2.0.20、对应 Address Library、OAR。无需 F NPC Mount、Paola、Piggyback 或 RSE。
未增加行为图，不需要为本包重新运行 Pandora。保留 OAR 预加载；当前整合的重复动画过滤已开启。
当前保留骑手OAR层的636个动作路径，覆盖男女、武器/魔法、移动和跳跃入口。NPC爬行由Crawl.nmc提供；此前10套已禁用的NPC OAR目录及6360个旧动作别名已清理。保持OAR重复动画过滤开启。

日志由INI的LogLevel统一控制：0完全关闭且本次运行不创建/改写日志，1仅错误，2错误与警告，3基础运行信息，4完整限量诊断。启用3或4时日志位于Documents/My Games/Skyrim Special Edition/SKSE/NPCMounts.log；4级每次骑乘最多1200组、每0.5秒一组运动诊断。旧DebugLog仅在没有LogLevel时迁移，0映射为关闭、1映射为4。日志不代表功能验收。

## 0.2.0 配置

缩放、速度倍率与长按时间步长0.05；跳跃0.1；座位偏移0.5；朝向1度；步态速度阈值5。范围、默认值不变；INI与菜单共用取整规则，旧的非档位数值会在读取或应用时就近取整。

F1打开已安装的SKSE Menu Framework，选择“NPC坐骑 / 骑乘配置”。调整后点击“保存并应用”；“恢复默认值”仅填入草稿，仍需保存。可从INI重新读取并应用。
配置文件：`SKSE/Plugins/NPCMounts.ini`。MO2运行时保存可能写入Overwrite或指定输出Mod；以MO2虚拟目录的最终获胜文件为准，不要误以为源Mod一定被原地写入。

- 覆盖NPC缩放默认关闭，保留各NPC原scale；开启后可选0.5—3，关闭或B还原原scale。
- 速度倍率1—2，基于当前SpeedMult加自身临时差值，不每帧重复累加；骑乘时同步作用于玩家移动控制器，下骑移除玩家差值，B移除NPC差值。
- 自动座位跟踪始终启用，读取SaddleBone或Spine2背骨及双方实际模型比例；可调整高度、前后、左右及NPC朝向偏角。即使关闭缩放覆盖也继续跟踪。
- 长按阈值0.25—2秒（必须超过阈值），默认0.25秒。上下骑使用固定0.85秒姿态过渡，不再显示或保存动画时长；旧INI的两个时长键忽略。
- 可配置跳跃、后退、Ctrl/潜行、Alt、战斗输入拦截、步态阈值和诊断日志。默认保留跳跃，禁止后退/潜行/Alt/战斗动作。
- 下骑键0使用游戏交互键；其他值为十进制键盘扫描码，不是Windows虚拟键码。

座位修正在玩家行为图生成的姿态输出内完成，不在动画/SMP之后反复写NiNode或调用UpdateDownwardPass。下骑使用包内31帧人形姿态资源，从骑坐经抬腿过渡到站姿，并移动至可选侧边。支持基础99骨及前99根名称、父索引一致的扩展骨架，包括当前安装的126骨XPMSSE；扩展轨道不覆写。不兼容时拒绝骑乘并记录原因；菜单“座位输出”用于检查该回调是否实际执行。极端体型、镜头、其他动画钩子和物理发丝的实际效果仍需游戏验证。
co-save版本5保存NPC原scale与自身速度差值，兼容版本1—4；独立RIDE记录用于读档撤回玩家临时速度和下骑锁定。读档不自动续骑。
Menu Framework为可选配置界面；缺失时仍读取INI，修改INI后重启游戏。没有增加其他Mod依赖。

0.2.1自检：下骑等待末帧姿态实际输出；输出停滞最多额外等待0.25秒并记录警告后释放，避免卡住。座位输出与清理互斥，模型/背骨失效时停用旧目标。缩放只在启用、配置改变或读档后写入，不因引擎量化反复SetScale。速度账本仅登记实际写入的差值，还原不忽略微小残值。INI支持UTF-8 BOM与float无损精度；重读失败保留当前配置及草稿，不误报成功。升级部署不覆盖已有INI。

## 0.3.0 新增法术

- C·固定坐骑：仅限已由A转换、未骑乘、未牵引的NPC。生成固定桩和绳环，暂停AI及临时清除队友标志，阻止自主跟随；C期间姿态暂停，不影响非固定坐骑的爬行。外部强制传送完全放行，无MoveTo/SetPosition拦截，不拉回原坐标。跨cell或离原位超过32单位后，待目标cell附着且3D加载才解除固定、恢复AI/队友标志并清理道具；保留A转换状态。不是绝对物理锁定，较小外部位移不纠正。B可主动解除。BIND v2保存队友状态，兼容v1；旧v1首次加载时记录当时的队友标志。
- D·束缚敌对目标：仅接受当前对玩家敌对的存活兼容人形NPC；佩戴绳环、停止战斗，束缚期间抑制双方敌对判定与再次开始战斗。不会把目标永久变成友军或修改原阵营。B解除后允许原有敌对逻辑恢复；D不自动转换为坐骑。
- E·牵引坐骑：通过实际LeashFramework接口，把绳索挂在NPC背骨，持绳人为玩家，启用牵引并禁用本次牵引的布娃娃拉拽；保留人形爬行动作。基础绳长100、最大220游戏单位。目标已存在牵引时拒绝覆盖。E/F需要已启用LeashFramework 1.1.7、Leash.esm及其自身前置；缺失不影响A～D。
- F·解除牵引：断开本插件创建的绳索并由框架删除独立绳模型，NPC保持坐骑状态。C和E互斥，束缚或牵引期间禁止骑乘。
- B统一解除：优先当前坐骑，其次准星NPC；无目标解除全部。删除C固定桩、解除C/D绳环并尝试重新装备原手部护甲、恢复接管前状态；E异步断开完成后才还原坐骑。原护甲按基础物品恢复，不承诺区分同名护甲不同附魔实例。卸载前先执行B无目标还原，保存退出。

C/D绳环为复制原版PrisonerCuffs记录；固定桩本地复用DD模型，仅引用原版贴图，无DD运行前置，不修改DD文件。LeashFramework只调用接口，不改其源码/文件。素材未经授权不公开再分发。保留原INI取值、种族与636个有效骑手动作路径。
新增BIND/TETH co-save记录独立于既有NMNT v5/RIDE。缺框架或初始化失败时拒绝相关操作。需实测C随从快速旅行、D敌对停止及B恢复、E/F绳索/移动、保存读档；离线模拟不能证明这些引擎效果。

## 构建命令

0.3.1：牵引检查/创建分离，读档先核实持绳人；查询单次在途，派发失败最多3次、间隔至少1秒，请求10秒未返回停止自动调用。B可在接口故障时还原本地状态，但未确认的绳索保留清理记录并提示，不宣称已断开；不要在绳索清理未确认时卸载。F可对没有在途修改调用的故障重新确认；有在途创建/断开时不重复派发。新增跨会话施法隔离、C位置修正重入保护及B原生命状态恢复，详见docs/AUDIT-0.3.1.md。

需要 Visual Studio 2022 C++、CMake、Node，以及已安装 CommonLibSSE 的依赖前缀：

```powershell
.\tools\build.ps1 -Dependencies '<CommonLib CMake prefix>' -SkyrimData '<Skyrim Data>' -Codec '<PyNifly HKX目录>' -CrawlSource '<三段爬行动作目录>' -BoundSource '<99轨束缚待机HKX>' -RiderSource '<Phantom Horse Base Sprint mt_sprintForward.hkx>'
node .\tests\verify-package.cjs
```

`build.ps1` 生成 ESP、DLL、默认INI、Dismount.nmp和Rider.nmr；Rider.nmr从本地Phantom Horse骑手动作生成，运行时不依赖Phantom Horse。基础动画需先使用 `tools/build-animations.py` 生成到 `dist`，并保留build/animations缓存供下骑制作。Python可用-Python指定。
离线动画工具参数可运行 `python tools/build-animations.py --help` 查看。
工具依赖 numpy、lz4、bethesda-structs、PyNifly HKX 编解码器、HKX2 转换器及 hkxcmd；它们不是游戏前置。
校准姿势通过 `--calibration` 指定；0.1.6同时传入 `--crawl-dir`，读取用户已有的F NPC Mount的97789动作目录，使用人形爬行原动作并稳定乘坐点。
生成后的游戏包不读取该 Mod。未经确认素材授权，不发布这些生成动画到公共仓库。

`dist` 是完整 MO2 候选包；构建脚本不更改游戏或 MO2。编译报告在 `reports`，完整方案复核在 `docs/REVIEW.md`。

Git不包含本地复用的游戏模型或生成动作。构建完整包前，需自行从已获授权的DD安装复制 `meshes/devious/furniture/kimy/restraintpost_static.nif` 到 `assets/meshes/NPCMounts/restraintpost_static.nif`，并按上述步骤生成动作；只克隆源码不会得到可直接安装的完整Mod。
