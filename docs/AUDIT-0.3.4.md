# 0.3.4 — 2026-10-15 深入检查

## 确定问题与修复

1. 紧急下骑在跨cell、死亡或模型卸载时仍无条件对NPC及玩家调用SetPosition。新增断言在0.3.3函数上失败，确认紧急路径存在坐标写入。现仅正常完成下骑进行位置交接，紧急退出释放骑乘状态与控制器标志，不写双方位置。该证据不等于已复现游戏CTD。
2. 骑乘同步仅比较双方cell相等，未阻止同一未附着cell或缺玩家/NPC模型时写位置。新增ActorReady/RideReady检查，进入骑乘、SyncMount本身、NPC更新前后与玩家Tick均核对加载状态；强制传送或加载中断会紧急下骑，不拉回旧区域。
3. 0.3.3只延迟普通接管，B及C/D Release仍可能操作未就绪Actor。现保存restoreRequested/releaseRequested，等待cell附着且3D存在后执行；保存格式不变。批量B也保留未加载请求，C强制传送继续放行。
4. 加载事件的延迟任务和PostLoad都可能在3D就绪前返回，普通Tick之前不会补发姿态初始化。现利用原有animation=-1会话状态补做一次ResetPose（派系先置0再发停止/默认姿态事件），共享加载事件和PostLoad的同一实现；完成后不反复重启动作。
5. ActivateInput延迟上骑任务和对话结束任务缺少会话检查。现捕获Extras::Session，拒绝旧存档任务；Revert同时清除suppressedButtons，避免旧存档按键拦截状态影响新存档。
