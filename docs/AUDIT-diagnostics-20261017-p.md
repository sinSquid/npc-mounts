# P：单次会话诊断采集（2026-10-17）

仅增加观察和日志；不改施法条件、牵引参数、重试次数、步态、座位、移动和跳跃控制。保留O版规则及N版安装链修复。

## 采集内容

- 每次启动独立 NPCMounts-runs/日期-时间-毫秒-PID-启动计时.log，NPCMounts.log为最新镜像。新日志先建立历史文件，不依赖下一次启动才归档；不自动删除历史。升级前旧日志另行备份。
- 日志有时间戳；施法执行使用操作编号和目标RefID，LeashFramework调用带请求号及异步上下文，绳索阶段带目标和token。首次只读施法事件与效果命中分开记录；不会把未命中误称为绑定逻辑失败。
- 目标快照包含Ref/Base/名称/种族/位置/cell/scale/speed/AI/生命状态/敌对/3D/控制器就绪。记录绑定判定、屏幕提示、固定桩ID、接绳回调、断绳/失效事件、还原完成和存取档消息。
- 卸装仍用原Unequip调用；记录返回值，并在本次卸装后仅取一次背包快照，核对每件目标装备的总数与穿戴标志。不增加周期装备扫描，不改物品数量。即时快照不能证明其他Mod稍后不会重新穿装。
- 初始配置及骑乘配置有日志；保留原菜单保存的四阶段刷盘信息。

## 限频和边界

- 原骑乘数据0.5秒/组，每次骑乘最多1200组；达到上限明确记录。下次骑乘重置原预算。
- 更新前后每条运动阶段另有0.5秒限频；步态变化共享每线程10Hz上限。运动明细为debug，按骑乘采样批量flush，避免每条阶段记录都刷盘。
- 常规牵引所有权查询的请求/响应日志共享2秒采样门；失败以及连接/断开等事件仍记录。沿用已有VM调用，不增加查询次数或后台线程。
- 稀有操作事件info立即flush。每次运行写历史及最新两个文件；存在非零I/O开销，未游戏测量FPS，不能承诺性能影响为零。突发崩溃最后一批尚未flush的debug记录可能缺失。
- 无新引擎钩子；只新增原生TESSpellCastEvent只读监听，限定本ESP且玩家施法。所有业务事件继续kContinue。
