# I：骑乘步态停止与动画切换

2026-10-17，基于H继续修改；DoM备用交互仍保持撤销。

## 实现

1. 骑乘使用独立Motion::RideState。移动输入长度不超过0.1时，物理修正速度不再驱动走/跑；停止立即选择idle。原地有明确转向仍保留转身动作，不把转身误当作前进。正常前进、横移、后退与INI步态阈值保留。非骑乘牵引仍使用原Motion::Choose，不把玩家输入错误用于被牵引NPC。
2. 不再因任意离地或跳跃请求计时尚未结束而选择跑步。只有接受跳跃输入后，在请求窗口内检测到新离地且向上速度，才锁存跳跃；跳跃全程保持奔跑爬行动画。连续接地0.12秒后结束锁存，避免一帧接触噪声反复切换；物理运动、原生重力与跳跃高度系数不变。
3. 起跳确认时消费请求计时，防止同一请求因离地/接地波动重复放大向上速度。上下骑、失效引用下骑、B触发下骑及读档Revert清理新步态状态，不增加存档字段。
4. 走/跑/冲刺等活动步态改变需连续稳定0.12秒，停止与从idle开始不延迟。原速度阈值迟滞继续保留。Crawl在前进走/跑/冲刺之间保持归一化播放进度，不再每次切换从零帧重放；idle、反向、转身切换仍从起始帧过渡。没有新增第二套动画播放器或运行时NiNode写入。
