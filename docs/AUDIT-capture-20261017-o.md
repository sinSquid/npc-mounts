# O：束缚敌对目标规则扩展（2026-10-17）

## 用户规则与实现

- 已坐骑化：D 复用 C 的固定流程，不要求敌对，不重复转换/卸装/加入敌对抑制。已有玩家牵引绳按原 C 路径先解除再接桩绳。
- 未坐骑化：仍须敌对兼容人形。转换、固定桩及记录建立成功后调用既有 Wardrobe::Undress，再装备束缚环、停止战斗并请求连接固定桩绳索。
- 卸装仅 Unequip，衣服/护甲仍在目标自己的背包；不转移、删除、复制物品。皮肤、头饰、武器、任务及受保护装备等既有排除规则保持。
- 依赖缺失、非敌对普通目标、生成桩或转换失败、已固定和正在骑乘时，不新增卸装。对已捕获目标重施不重复卸装。
- 绳索异步失败仍按现有实现解除固定，保留已完成的坐骑化；已卸下的衣服留在目标背包，不在异步失败时强制重新穿回。B 的解绳、固定道具清理、原状态恢复保持；旧手部装备按既有束缚环还原逻辑处理，不主动重穿整套衣服。

## 修改与验证

生产源只在 Extras.cpp 引入 Wardrobe、将已转换 D 分派到 C、并增加成功新捕获后的卸装调用。Wardrobe.cpp、RideHooks、Motion、Seat、INI 未修改。

生成前先重建原版 ESP，与已安装文件 SHA256 完全相同。更新生成器中的 Capture 描述后，逐记录/字段比对仅 MGEF 0x807 DNAM、SPEL 0x80B DESC、BOOK 0x813 DESC 改变，其他字段、ID、名称和记录保持。
