## 第二阶段：骑乘运动与显示

### 单一物理主体

保留玩家原生物理控制器作为整体移动主体，负责地形、墙体、行走及一次跳跃；NPC 是跟随显示目标，骑乘时不再接受独立寻路位移。玩家骨骼负责骑手显示，不能用显示偏移后的骨骼反推 NPC 物理位置。

不照搬参考项目的“禁用玩家全部移动”：它们的乘客/承载者关系不同，这样做可能再次导致本项目不能移动。

### 更新、座位与碰撞

L 轮收敛：保留现有座位计算和配对碰撞过滤，不再叠加新位置修正。对照本机 SE 1.5.97 的调用者/被调用者机器码后，在 NPCUpdate 同步坐骑位置之后、原始更新期间，按线程局部的精确 Actor 指针跳过它的 ApplyMovementDelta；其他角色及玩家原调用保持。退出此次调用立即恢复局部选择，不持久保存指针。

- 核实当前运行版本实际调用顺序，选择一个同步阶段，消除多个入口重复追赶位置。
- NPC 根位置来自同一个物理主体；座位由 NPC 模型空间背部锚点、双方缩放和配置偏移计算。
- 仅平滑轻微局部背部起伏；不平滑真实地形、跳跃高度，不反复抬压控制器。竖直方向统一记为 Z。
- 玩家保留世界碰撞；避免跟随 NPC 反向挤推玩家。不全局关闭其他 NPC 碰撞，退出恢复本插件拥有的修改。
- 保持动画更新，不用 EnableAI(false) 冻结 NPC；保留已有静止、行走、奔跑判定与滞回。
- 核对原生姿态输出与 OAR 职责，避免重复启动同一动作；不同时引入新行为图或更换已有效的动作资源。

### 输入与跳跃

- MouseSteering默认开启：鼠标准星方向平滑转向，A/D辅助转向；关闭则鼠标仅观察，A/D转向。W/S沿坐骑朝向前后移动，后退服从现有开关。
- 持续设置 fovSlideMode 不是已验证的自由观察方案，须核实其与原生移动的关系，再做最小替换。
- L 轮改用核实过的 ThirdPersonState::SetFreeRotationMode 接口，在拥有骑乘控制时启用 freeRotationEnabled，退出后继续原处理；不再写 fovSlideMode。控制器仍只保留玩家一次物理起跳，未另造跳跃驱动。
- Space 仅触发一次整体物理跳跃，不另外给 NPC 叠加跳跃位移。玩家显示保持骑姿，NPC 空中播放既定爬行奔跑动作。
- JumpHeightMultiplier 保留 [0.8,2]、步长 0.1，仅起跳时应用一次。
- 潜行/战斗按现有配置限制；保留还原魔法入口和菜单输入。不承诺屏蔽绕过输入队列的所有第三方动作。

### 上下骑

- U轮按用户要求移除上下骑过渡，直接进入/退出静态骑姿，不调用配对动画。
- 长按下骑超过配置阈值，默认严格大于 0.25 秒；轻触不下骑。
- 不再有过渡锁定水平输入；无侧边落点时原地退出，不要求开阔地。
- 退出归还本插件的移动、碰撞、输入和相机控制；死亡等紧急退出不等待普通动画。

## 第三阶段：四个魔法与控制权交接（按后续合并需求更新）

| 魔法 | 保留的职责及边界 |
| --- | --- |
| 人魅-人形坐骑化 | 记录原值，保持种族、美化及人形骨架，进入爬行待机并允许上骑；重复施放不覆盖初始快照。UndressOnConvert默认关闭；勾选后成功施法一次性卸装，保留装备排除规则，不持续脱装或强制重穿 |
| 人魅-固定坐骑 | 仅接收坐骑形态，生成固定物及连绳、限制正常移动；外部强制传送时释放固定，不强拉回、不阻塞传送 |
| 人魅-牵引坐骑 | 添加/解除切换；牵引时 LeashFramework 独占移动，本插件只维护爬行显示；解除固定绳同时清理固定物，不覆盖第三方绳 |
| 人魅-解除坐骑化与束缚 | 统一退出：下骑、清理自有绳/固定物、停止姿态覆盖、撤回自有状态修改、清除最近坐骑记录 |

固定、玩家牵引、骑乘不得同时驱动同一目标。现有异步绳请求必须结束/取消后再交接，避免晚到回调重建已解除关系；沿用既有必要生命周期机制，不另造大状态框架。

旧敌对束缚仍可清理，不重置阵营；该法术和授书入口停用。旧卸装法术迁移普通坐骑化，旧书重定向；保留已有FormID，不自动注入未学魔法。目标B与无目标B的现有语义保留。

## 保存读档、复活和最近坐骑

- 保存稳定状态和必要原值，不保存指针、控制器地址或中途动画进度。
- 读档保留转换/固定/牵引记录，但不自动恢复玩家骑乘；实际加载后重取运行时对象并核查绳关系。
- 复活重置重新绑定，不复用旧骨架/控制器，不重写初始还原快照。
- 玩家传送只处理最近成功骑过的一个目标；固定时不传送，也不回退挑选更早目标；牵引时不抢框架控制权。
- B 仅撤回本插件拥有的改动，不覆盖其他 Mod 后续的全部状态。未加载目标延后完成，不循环强制加载。
